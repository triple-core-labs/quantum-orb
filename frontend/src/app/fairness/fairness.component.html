How an orb is decided

  1. You pay. The transaction records the block it landed in and nothing else.
  2. {{ revealDelay() }} blocks later, the hash of that future block is used as the seed. It did not exist when you paid, so nobody could predict it.
  3. The seed decides the rarity, then a second hash of the same seed decides the points inside that rarity's range.

Every input is on chain. Anyone can recompute any result from the block hash, the player address and the commit block.
